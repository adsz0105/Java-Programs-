# Java Programs

A collection of Java programs that can be run on any Java-supported IDE or through the Command Prompt.

## Running Programs via Command Prompt

1. Create or open a folder for your Java files.
2. Create a new file and save the code as `ClassName.java` (the filename must match the class name).
3. Open the folder and type `cmd` in the address bar to launch Command Prompt in that directory.
4. Compile the program:
   ```bash
   javac ClassName.java
   ```
5. Run the program:
   ```bash
   java ClassName
   ```

## Requirements

- Java Development Kit (JDK) installed
- Any Java IDE (optional)
